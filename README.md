# Multi Mob Library

Multi Mob Library is a core library for Minecraft mob mods.

This is the Forge 1.20.1 port and is required by Primitive Mobs.

## Requirements

- Minecraft 1.20.1
- Minecraft Forge 47+

## Version

Current version: **1.0.2**
