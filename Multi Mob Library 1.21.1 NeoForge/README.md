# Multi Mob Library

Multi Mob Library is a core library for Minecraft mob mods.

This is the NeoForge 1.21.1 port and is required by The Summoner and Primitive Mobs.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1+
- Java 21

## Version

Current version: **1.21.1-1.0.0**
